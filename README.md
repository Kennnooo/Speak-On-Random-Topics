# Speak On This

A single-page web app for practicing impromptu speaking. Draw a random 2–3 word topic, take a minute to prepare using a simple 3-step framework, then speak for a minute without stopping.

Inspired by "Table Topics" style impromptu speaking drills (the format used in speaking clubs like Toastmasters) and a public speaking practice reel on Instagram.

## How it works

1. **Draw a topic** — pulls a random prompt from a deck of ~135 topics across categories: Everyday, Opinion, Hypothetical, Nostalgia, Abstract, Storytelling, Hot Take, Describe, Would You Rather, Philosophical, Political, and Easy.
2. **Prepare (1 min)** — a 60-second countdown with a built-in framework to structure your thinking:
   1. **What / Why** — define the topic plainly, why it exists or matters
   2. **Weigh it** — one good thing about it, one bad thing
   3. **Land it** — what you're grateful for, or your takeaway/conclusion

   The panel highlights each step automatically as the minute passes. You can skip ahead to speaking early if you're ready.
3. **Start speaking** — a 60-second countdown with a color-coded ring (green → amber → red) and a warning chime as time runs low.
4. **+15s / +30s / +45s** — optional buttons to add extra time to either the prep or speaking countdown, available before or during either phase. The default stays 60 seconds unless you use these.

Other details:
- Recently drawn topics aren't repeated until the deck has cycled through a good chunk of itself.
- The topic is locked while prep or speaking is in progress — you can't accidentally redraw mid-flow.
- Keyboard shortcuts: `Space` to draw a topic, `Enter` to start/stop/advance.
- All sounds (start chime, warning beeps, end buzzer) are generated in-browser — no audio files.
